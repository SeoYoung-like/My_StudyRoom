* DELETE



# 학습 키워드 정리

## 1. 주요 키워드 목록

| 키워드               | 분류             | 중요도 | 한 줄 설명                                                   |
| -------------------- | ---------------- | ------ | ------------------------------------------------------------ |
| HTTP 메서드          | 필수 암기 키워드 | 5      | 클라이언트가 서버에게 요청 목적을 전달하는 명령어이다.       |
| GET                  | 필수 암기 키워드 | 5      | 서버에서 데이터를 조회하거나 가져올 때 사용하는 메서드이다.  |
| POST                 | 필수 암기 키워드 | 5      | 서버에 데이터를 전송하거나 새로운 리소스를 생성할 때 사용하는 메서드이다. |
| PUT                  | 필수 암기 키워드 | 4      | 기존 리소스를 전체 데이터로 통째로 교체할 때 사용하는 메서드이다. |
| PATCH                | 필수 암기 키워드 | 4      | 기존 리소스의 일부 필드만 수정할 때 사용하는 메서드이다.     |
| DELETE               | 필수 암기 키워드 | 4      | 서버에 있는 특정 리소스를 삭제할 때 사용하는 메서드이다.     |
| requests 라이브러리  | 일반 학습 키워드 | 4      | Python에서 HTTP 요청을 보내기 위해 사용하는 라이브러리이다.  |
| requests.get(url)    | 필수 암기 키워드 | 5      | GET 요청을 보내 데이터 조회를 수행하는 requests 함수이다.    |
| requests.post(url)   | 필수 암기 키워드 | 5      | POST 요청을 보내 데이터 전송 또는 생성을 수행하는 requests 함수이다. |
| requests.put(url)    | 일반 학습 키워드 | 4      | PUT 요청을 보내 전체 수정을 수행하는 requests 함수이다.      |
| requests.patch(url)  | 일반 학습 키워드 | 4      | PATCH 요청을 보내 일부 수정을 수행하는 requests 함수이다.    |
| requests.delete(url) | 일반 학습 키워드 | 4      | DELETE 요청을 보내 리소스 삭제를 수행하는 requests 함수이다. |
| CRUD                 | 비교 키워드      | 4      | Create, Read, Update, Delete로 HTTP 메서드 역할과 대응되는 데이터 처리 개념이다. |
| Create               | 비교 키워드      | 3      | POST와 대응되는 데이터 생성 개념이다.                        |
| Read                 | 비교 키워드      | 3      | GET과 대응되는 데이터 조회 개념이다.                         |
| Update               | 비교 키워드      | 3      | PUT, PATCH와 대응되는 데이터 수정 개념이다.                  |
| Delete               | 비교 키워드      | 3      | DELETE와 대응되는 데이터 삭제 개념이다.                      |
| REST API             | 일반 학습 키워드 | 4      | 상황에 맞는 HTTP 메서드 사용을 권장하는 API 설계 방식이다.   |
| 클라이언트           | 일반 학습 키워드 | 3      | 서버에 요청을 보내는 Python 코드, 브라우저, 모바일 앱 등을 의미한다. |
| 서버                 | 일반 학습 키워드 | 3      | 클라이언트의 요청을 처리하고 응답을 반환하는 대상이다.       |
| 요청                 | 필수 암기 키워드 | 4      | 클라이언트가 서버에 특정 작업을 요구하는 행위이다.           |
| 응답                 | 일반 학습 키워드 | 3      | 서버가 요청 처리 결과를 클라이언트에게 돌려주는 것이다.      |
| 요청의 목적          | 필수 암기 키워드 | 5      | HTTP 메서드가 서버에게 알려주는 핵심 의미이다.               |
| 요청 본문(body)      | 비교 키워드      | 4      | POST 등에서 서버로 보낼 데이터를 담는 요청 영역이다.         |
| params               | 필수 암기 키워드 | 4      | GET 요청에서 검색 조건을 URL 쿼리 문자열로 전달할 때 사용하는 옵션이다. |
| data                 | 비교 키워드      | 4      | 폼 데이터 형식으로 서버에 데이터를 전송할 때 사용하는 옵션이다. |
| json                 | 비교 키워드      | 4      | JSON 형식으로 서버에 데이터를 전송할 때 사용하는 옵션이다.   |
| URL 쿼리 문자열      | 일반 학습 키워드 | 3      | GET 요청에서 검색 조건이 URL 뒤에 붙는 형식이다.             |
| status_code          | 일반 학습 키워드 | 4      | 서버 응답의 처리 상태를 확인하는 값이다.                     |
| response.text        | 일반 학습 키워드 | 3      | 서버 응답 본문을 문자열로 확인할 때 사용하는 속성이다.       |
| httpbin.org          | 일반 학습 키워드 | 3      | 보낸 HTTP 요청 내용을 응답으로 확인할 수 있는 테스트용 서비스이다. |
| 멱등성               | 비교 키워드      | 4      | 같은 요청을 여러 번 보내도 결과가 동일한지 여부를 나타내는 개념이다. |
| 200 OK               | 일반 학습 키워드 | 3      | 요청이 정상적으로 처리되었음을 나타내는 대표적인 응답 상태이다. |
| 201                  | 일반 학습 키워드 | 2      | 데이터 생성 요청이 성공했을 때 일반적으로 사용되는 상태 코드이다. |
| 204 No Content       | 일반 학습 키워드 | 3      | 삭제 등 처리 성공 후 반환할 본문이 없음을 나타내는 상태 코드이다. |
| API 문서 해석        | 필수 암기 키워드 | 5      | HTTP 메서드와 URL을 보고 어떤 요청을 보내야 하는지 판단하는 능력이다. |
| GET /books           | 일반 학습 키워드 | 3      | 책 목록을 조회하는 API 요청 예시이다.                        |
| POST /books          | 일반 학습 키워드 | 3      | 새 책을 등록하는 API 요청 예시이다.                          |
| GET /books/{id}      | 일반 학습 키워드 | 3      | 특정 책을 조회하는 API 요청 예시이다.                        |
| PATCH /books/{id}    | 일반 학습 키워드 | 3      | 특정 책의 일부 정보를 수정하는 API 요청 예시이다.            |
| DELETE /books/{id}   | 일반 학습 키워드 | 3      | 특정 책을 삭제하는 API 요청 예시이다.                        |
| GET과 POST           | 비교 키워드      | 5      | GET은 데이터 조회, POST는 데이터 전송 또는 생성에 사용된다.  |
| PUT과 PATCH          | 비교 키워드      | 5      | PUT은 전체 수정, PATCH는 일부 수정에 사용된다.               |
| data와 json          | 비교 키워드      | 5      | data는 폼 데이터, json은 JSON 형식 전송에 사용된다.          |
| GET과 params         | 비교 키워드      | 4      | GET 요청에서는 검색 조건 전달에 params를 자주 사용한다.      |
| POST와 body          | 비교 키워드      | 4      | POST 요청은 요청 본문에 데이터를 담아 서버로 전송한다.       |
