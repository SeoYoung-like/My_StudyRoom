# 학습 키워드 정리

## 1. 주요 키워드 목록

| 키워드                    | 분류             | 중요도 | 한 줄 설명                                                   |
| ------------------------- | ---------------- | ------ | ------------------------------------------------------------ |
| requests                  | 필수 암기 키워드 | 5      | Python에서 웹 서버에 HTTP 요청을 보내고 응답을 받아오는 라이브러리입니다. |
| HTTP 통신                 | 필수 암기 키워드 | 5      | 웹에서 데이터를 주고받기 위한 기본 통신 방식입니다.          |
| Request                   | 필수 암기 키워드 | 5      | 클라이언트가 서버에 데이터 요청이나 저장 요청을 보내는 행위입니다. |
| Response                  | 필수 암기 키워드 | 5      | 서버가 클라이언트 요청에 대해 데이터나 오류를 반환하는 결과입니다. |
| 클라이언트                | 일반 학습 키워드 | 4      | 요청을 보내는 주체로, 문서에서는 Python 코드가 이에 해당합니다. |
| 서버                      | 일반 학습 키워드 | 4      | 요청을 받아 처리하고 응답을 반환하는 웹사이트나 API입니다.   |
| URL                       | 필수 암기 키워드 | 5      | 서버의 특정 자원 위치를 나타내는 웹 주소입니다.              |
| Scheme                    | 일반 학습 키워드 | 3      | URL에서 http 또는 https 같은 통신 규약을 나타내는 부분입니다. |
| Host                      | 일반 학습 키워드 | 3      | URL에서 목적지 서버의 도메인 이름을 나타내는 부분입니다.     |
| Path                      | 일반 학습 키워드 | 3      | 서버 내부에서 접근할 자원의 구체적인 위치를 나타냅니다.      |
| Query String              | 필수 암기 키워드 | 4      | URL 뒤에 붙어 추가 조건을 key=value 형태로 전달하는 부분입니다. |
| params                    | 필수 암기 키워드 | 4      | requests에서 query string을 딕셔너리 형태로 깔끔하게 전달하는 파라미터입니다. |
| 상태 코드                 | 필수 암기 키워드 | 5      | 서버가 요청 처리 결과를 숫자로 알려주는 응답 정보입니다.     |
| 200 OK                    | 필수 암기 키워드 | 5      | 요청이 성공적으로 처리되었음을 의미하는 상태 코드입니다.     |
| 201 Created               | 일반 학습 키워드 | 3      | POST 요청으로 데이터 생성이 성공했음을 의미합니다.           |
| 400 Bad Request           | 필수 암기 키워드 | 4      | 요청 형식이나 파라미터가 잘못되었음을 의미합니다.            |
| 401 Unauthorized          | 필수 암기 키워드 | 4      | 인증되지 않아 로그인이 필요한 상태를 의미합니다.             |
| 403 Forbidden             | 필수 암기 키워드 | 4      | 인증은 되었지만 접근 권한이 없음을 의미합니다.               |
| 404 Not Found             | 필수 암기 키워드 | 5      | 요청한 URL이나 자원이 존재하지 않음을 의미합니다.            |
| 429 Too Many Requests     | 일반 학습 키워드 | 3      | 너무 많은 요청으로 API 속도 제한에 걸린 상태를 의미합니다.   |
| 500 Internal Server Error | 필수 암기 키워드 | 5      | 서버 내부 문제로 요청 처리가 실패했음을 의미합니다.          |
| 503 Service Unavailable   | 일반 학습 키워드 | 3      | 서버가 일시적으로 요청을 처리할 수 없는 상태를 의미합니다.   |
| 2xx                       | 비교 키워드      | 5      | 요청이 성공적으로 처리되었음을 나타내는 상태 코드 그룹입니다. |
| 3xx                       | 비교 키워드      | 3      | 요청한 자원이 다른 위치로 이동했음을 나타내는 리다이렉트 그룹입니다. |
| 4xx                       | 비교 키워드      | 5      | 클라이언트 요청에 문제가 있음을 나타내는 상태 코드 그룹입니다. |
| 5xx                       | 비교 키워드      | 5      | 서버 내부 문제로 요청 처리가 실패했음을 나타내는 상태 코드 그룹입니다. |
| Header                    | 필수 암기 키워드 | 5      | 요청과 응답에 함께 포함되는 메타데이터 정보입니다.           |
| Body                      | 필수 암기 키워드 | 4      | 실제 데이터가 담기는 영역으로 HTML, JSON 등이 포함됩니다.    |
| User-Agent                | 일반 학습 키워드 | 3      | 요청자가 브라우저인지 Python 코드인지 알려주는 Header 항목입니다. |
| Content-Type              | 필수 암기 키워드 | 4      | 전송하는 데이터의 형식을 알려주는 Header 항목입니다.         |
| Authorization             | 필수 암기 키워드 | 4      | 인증 토큰이나 키를 전달할 때 사용하는 Header 항목입니다.     |
| Accept                    | 일반 학습 키워드 | 3      | 서버에 원하는 응답 데이터 형식을 알려주는 Header 항목입니다. |
| requests.get()            | 필수 암기 키워드 | 5      | 지정한 URL로 GET 요청을 보내는 requests의 핵심 함수입니다.   |
| response.status_code      | 필수 암기 키워드 | 5      | 응답의 상태 코드를 확인하는 속성입니다.                      |
| response.url              | 일반 학습 키워드 | 3      | params가 반영된 실제 요청 URL을 확인할 때 사용하는 속성입니다. |
| response.headers          | 일반 학습 키워드 | 3      | 서버가 반환한 응답 Header 정보를 확인하는 속성입니다.        |
| response.json()           | 필수 암기 키워드 | 4      | 응답 데이터를 JSON 형태로 변환해 읽는 requests 메서드입니다. |
| raise_for_status()        | 필수 암기 키워드 | 4      | 4xx, 5xx 상태 코드를 자동으로 예외 처리하는 메서드입니다.    |
| urllib                    | 비교 키워드      | 4      | Python 표준 HTTP 라이브러리지만 requests보다 코드가 길고 복잡합니다. |
| API 호출                  | 필수 암기 키워드 | 4      | 외부 서비스의 데이터를 가져오거나 전송하는 requests의 주요 활용입니다. |
| 웹 데이터 수집            | 일반 학습 키워드 | 3      | requests로 HTML을 가져와 크롤링이나 스크래핑의 첫 단계에 활용하는 작업입니다. |
| 크롤링                    | 일반 학습 키워드 | 3      | 웹 페이지 정보를 자동으로 가져오는 작업입니다.               |
| 스크래핑                  | 일반 학습 키워드 | 3      | 가져온 웹 데이터에서 필요한 정보를 추출하는 작업입니다.      |
| BeautifulSoup             | 일반 학습 키워드 | 2      | requests로 가져온 HTML을 분석할 때 함께 사용하는 파싱 라이브러리입니다. |
| Session                   | 필수 암기 키워드 | 4      | 로그인 상태를 유지하면서 여러 페이지를 탐색할 수 있게 해주는 객체입니다. |
| 쿠키                      | 일반 학습 키워드 | 3      | 로그인과 세션 유지 과정에서 관리되는 웹 상태 정보입니다.     |
| 자동화 스크립트           | 일반 학습 키워드 | 3      | 외부 서비스와 반복적으로 데이터를 주고받는 작업 자동화에 requests가 활용됩니다. |
| GET                       | 비교 키워드      | 4      | 서버에서 데이터를 가져오는 HTTP 요청 메서드입니다.           |
| POST                      | 비교 키워드      | 4      | 서버에 데이터를 생성하거나 전송할 때 사용하는 HTTP 요청 메서드입니다. |
| PUT                       | 비교 키워드      | 3      | 문서에서 다음 단계에 다룰 실제 요청 메서드로 언급됩니다.     |
| DELETE                    | 비교 키워드      | 3      | 문서에서 다음 단계에 다룰 실제 요청 메서드로 언급됩니다.     |
